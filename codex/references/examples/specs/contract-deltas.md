# Current Examples contract

The maintained example designs are owned by Sambl Web App Design. Local kit
primitives and variables remain the generation inputs; the kit's former Examples
page is not a design reference. Dashboard Shell is a component, while the screen
is Dashboard in Sambl Examples. Use that name in all screen descriptions and
result links. Preserve the specified canvas copy. Generic Menu/Navigation remain
generic; the Shell
contains the complete names/icons/states preset in all retained variants.

Group titles use matching-scale Default typography, not Accent. Figma Client Cell
uses the native multicolor Figma logo, floor-2 background and neutral-primary
outline in both Compact and Detailed. Avatars use the complete current Image
default. Grid md/lg remains native Grid; configure cards before Main Slot
insertion, then set only the inserted composition root to FILL, with clipping off.
Use current Auto Layout, true Slots and bound Section chrome without a Surface.

Production orchestration is one natural screen request. Component creation,
source self-check and screen assembly continue internally. Lab manifests,
historical file IDs, fixture dependencies, external acceptance and staged manual
preload prompts are not runtime prerequisites. General missing-dependency policy
applies to every absent component, icon, style or token.

# Help
General help: get_capabilities without identity. It lists current registered, active, caller-authorized capabilities without inspecting a file. Use the returned localized title, description and Examples catalogue; no other tool descriptions or references are needed for the list. entryKind describes what the entry tool supplies; capabilityEffect describes the eventual user action, not a write by a getter. executionAuthorized is false. An empty list gives no reason for absence; do not infer file incompatibility or a subscription problem. Answer in readable prose, then stop; do not start onboarding, show setup choices or call recognize_kit. For a request to start setup, load get_reference with sambl/onboarding. That entry skill owns the dialogue and follows each child's actual contract.
Examples catalogue questions such as "Which Sambl example screens can you generate?" also call get_capabilities without identity. Answer only from the returned authorized generate_examples.examples; never substitute generic Figma screen types. If that entry is absent, report its unavailability without inventing a reason. Do not retrieve a package or inspect a file for this question. An actual request to generate a screen starts get_example_package without screen.
Semantic color requests: retrieve sambl/semantic-colors for role values or explicit creation of managed semantic support; load only relevant references. Palette owns explicit new chromatic rows. Both entries reuse sambl/variables with variable_operation after admission. No new modes or automatic component rebinding.
Documentation: get_reference with sambl/semantic-colors, sambl/overview, sambl/onboarding, sambl/themes, sambl/platforms, sambl/size-class, sambl/kit-admission, sambl/collections, sambl/palette, sambl/slot-defaults, sambl/help or sambl/examples. Summarize readable text in the user's language, not raw result JSON. The examples/* references contain supporting design specifications; selected example packages provide their required instructions.
Release history and version questions:
- A direct "What's new in Sambl?" / "Что нового в Sambl?" calls get_changelog without identity and answers from that result. This needs no file, recognition, capability discovery or prior guide retrieval. These help rules document the conversation; loading them is not a prerequisite for a simple changelog question. Do not ask permission or start setup for a read-only general question.
- A question about release notes for this copy, or whether a newer release is registered, reads only the exact document-root sambl/kit-metadata string. Reuse an observation only for the same actual file and task while its freshness remains established; reread after a file switch or uncertainty. Never infer identity from the file name, matching component names, chat history or another file. Pass the exact raw string to recognize_kit without requestedCapability. Only that tool parses it. For a successful result use result.identity; for metadata_unsupported use only its observedIdentity for the read-only get_changelog lookup. No other blocked result supplies an identity for history. Never parse or reconstruct identity locally. General release history does not require a Design file. Historical lookup does not require support for file modifications: recognize_kit may return a declared unsupported identity without admission. This grants no modification support. If successful recognition already returned the exact same fresh identity, reuse it without another recognition call.
- Missing, malformed or foreign metadata cannot identify the copy's release. Say that clearly and offer general Sambl release history; do not silently substitute the latest identity, repair metadata or start setup. An actual read error stays a read error: ask to retry or select the intended file rather than classifying it as empty or foreign. If no current Design file is available for an explicitly file-specific question, ask the user to open or select it; never ask for technical IDs. Empty and third-party files may still request general release history without recognition.

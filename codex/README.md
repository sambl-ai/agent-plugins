# Sambl UI Kit

This package contains two skills: `sambl` for kit knowledge, exact color
calculations, optional preparation, release questions and feedback when available;
and `sambl-style-adaptation` for coherent restyling from visual references or a
named product style. Your agent uses its connected Figma tools to inspect and
edit the kit.

Sign in to Sambl through your client's connection prompt. Connect Figma
separately for file tasks and share the file you want to work on. Reuse existing
working connections. To edit a kit, use a copy you have permission to edit.

Try asking “Which variables control this input's focus ring?” or “Adapt this
kit to my reference and show what you changed and kept.” The wiki describes the
documented kit; the current file supplies live bindings and customizations.
Review the resulting appearance, dependencies and instance content.

After a package update, refresh or restart your client as needed.

See the [installation guide](https://github.com/sambl-ai/agent-plugins#readme)
for Codex, Claude Desktop/Cowork and Claude Code installation and updates.

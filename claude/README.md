# Sambl for Claude

Sambl helps you work with the Sambl UI Kit in Figma from Claude. Use it to
configure themes and platforms, preview palette and semantic color changes,
or build a Sign In or Dashboard example with the kit's components and styles.
Sign in to Sambl when prompted and connect Figma for tasks that use a design
file. To edit a kit, use a copy you have permission to edit.

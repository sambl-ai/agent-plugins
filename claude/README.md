# Sambl for Claude

Sambl helps you work with the Sambl UI Kit in Figma from Claude. The `sambl`
skill finds relevant kit knowledge, calculates colors and contrast, guides
optional preparation, and supports release questions and confirmed feedback.
The `sambl-style-adaptation` skill helps adapt a kit to visual references or a
named product style. Your agent inspects and edits the kit through its Figma
tools. Sign in to Sambl when prompted and connect Figma for file tasks. Use a
kit copy you have permission to edit, and review the resulting appearance,
dependencies and instance content.
